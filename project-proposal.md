Option 1: One-Page Proposal

<!-- _class: small -->

- **Problem**: What is the problem that you need to solve?
> People have different responsibilities in their daily lives, such as work, school, and housework. Keeping track of tasks, deadlines, and priorities in different places can make it easy to forget things or lose track of what needs to be done.

- **Solution**: What is your solution to the problem?
> Tamana is a task management app that allows users to keep their tasks and projects in one place. Users can organize tasks by category (work, school, life, etc.), set deadlines and priorities, update task statuses, and track their progress.

### Option 1: One-Page Proposal (cont.)

<!-- _class: small -->

- **Stage 1 tool** (working baseline):
> Python + FastAPI + SQLite (direct SQL queries).

- **Stage 2 tool** (higher-level tools or framework):
> FastAPI + SQLAlchemy ORM + Pydantic for database operations and data validation.

- **Automation tools** (e.g., Docker, GitHub Actions):
> Docker for containerization, GitHub for version control, GitHub Actions for CI/CD, and Hugo for documentation.

Even with Option 1, plan to use the ASE 230 Module 3 tools (Docker, Hugo, and GitHub) to document and automate your project.
